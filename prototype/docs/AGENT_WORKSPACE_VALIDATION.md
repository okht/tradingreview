# Agent 工作区验收

日期：2026-10-21

## 产品结构

- 正式入口为 `AgentWorkspace`，本地与云端一致。六步旅程和 `?legacy=1` 不再是可进入的产品路径。
- 新工作区没有交易、预设对话、学习项或演示模型。模型首次连接提示出现在空白会话；已有配置通过设置和输入框模型菜单管理。
- 侧栏包含新建复盘、历史复盘、检查项和设置。新建与切换保留原会话、材料与草稿。
- CSV / 只读接口在弹窗确认后进入会话；自然语言整理使用 Pi 返回候选记录，用户核对后才加入复盘范围。
- 对话持续收集背景并核对证据。资料在同一主滚动区域完整展开；检查项由回答生成并经用户编辑保存。
- 生成回答保留模型身份、材料版本和实际引用的证据快照。材料或模型变化取消旧请求；历史回答仍可查看，原引用定位到当次快照。
