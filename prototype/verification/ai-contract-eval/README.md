# 复盘输出契约挑战｜2026-10-22

本目录测试产品的输出校验边界。候选结果由评测代码构造，供应商为本机隔离的假服务；没有调用收费模型，没有改动用户工作区数据。不能用本报告估计真实模型错误率或代替真实模型任务质量评测。

## 基线与修复

`baseline-2026-10-22.json` 记录修复前观察。已有 59 条相关测试通过，但三个候选坏结果均通过真实 Pi 工具循环和前端转换：主回复使用事后公告归因并编造净利；合法成交引用附上错误数量/费用；换一种表达的满仓操作指令。另有仅引用成交就断言心理偏差的纯函数复现。

本轮修复要求主回复结论独立携带 `textEvidenceIds`，学习项独立携带 `evidenceIds`，不再借用其他结论引用。所有这些字段同样经过时点、回忆、合成材料边界检查。无引用主回复只允许中性核对引导或澄清问题；第几笔和具体时点的问句仍可使用。

成交数量、成交价、费用、净盈亏和投入收益率的常见数值表达与被引用成交的原始字段或确定性计算相对照。净盈亏/收益率回答须先读取 `get_summary`。缺价格、费用或未完成买卖周期时，不补造数值。仅有成交不能断言心理偏差或当时认知；相关解释须有用户背景依据并保留不确定性。

界面按每条结论编号引用，并在材料按钮上显示相同编号；学习项显示自己的依据。标题使用「依据材料整理的事实」，不会把结构通过等同于语义真实性验证。

## 重现

在项目根目录运行：

```text
node verification/ai-contract-eval/run.mjs
node --test tests/review-grounding.test.mjs
```

`cases.mjs` 为 28 条候选结果挑战，包含应拒绝和应接受的对照；`after-2026-10-22.json` 是本轮报告，28/28 符合预期。`tests/review-grounding.test.mjs` 共 33 条，还覆盖三个原始坏例穿过 Pi 循环时的拒绝、可见引用映射、学习项来源和核算工具要求。联合 AI、行情、持久化、对话回归 133/133 通过。

## 边界

引用存在、时点正确、部分数值匹配，均不能证明任意自然语言结论与证据的语义蕴含关系。当前数字和表达检查是有范围的保守护栏，仍可能存在未覆盖的同义改写或误拦截；真实模型质量评测须检查理由、归因、事实引用、澄清质量和正常任务完成率，并保留原始输出。用户引用的事实陈述、外部公告数字与交易计算也需要分别判断。本轮不宣称已解决所有事实幻觉。
