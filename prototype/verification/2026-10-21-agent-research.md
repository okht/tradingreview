# Agent 证据检索与交易方法验证

## 本次范围

- 通过已配置的扶摇或 iFinD HTTP MCP，发现并调用明确标记为只读的工具，保留原始响应字段、关联交易和时间属性。
- Pi Agent 在对话中提出交易方法、改进、历史比较、保存版本和批量回测意图，后端校验并执行。
- 无决策理由时允许生成候选行为规则，展示相符交易、反例、无法判断及有信号未交易的节点。
- 原方法与改进方法分别保存；可选择已有兼容行情和时间区间，按收益率、回撤、夏普排序。
- 弹窗打开时焦点进入容器，避免自动触发关闭按钮 Tooltip；保留键盘导航和悬停提示。

## 验证结果

- Node 全量测试：318 / 318 通过。
- 新增策略引擎、MCP 检索、Agent 与研究服务集成测试覆盖：成本、次根开盘成交、T+1、资金不足、未来信息隔离、错误数据、候选规则校验、数据源失败与中止、伪造执行完成声明、版本保存和批量回测。
- Vite 本地构建通过。
- 浏览器实际走通：保存原方法 → 生成改进版本 → 填写 100000 元起始资金 → 比较 → 保存 V2 → 方法库选择两个已有合成数据集 → 批量回测。
- 刷新后保留原方法、V2 和比较结果；无理由的 42 笔合成成交可用于候选规则推导。
- 独立 UI 验证：12 个合成数据集跨页全选、结果每页 10 项、切换方法不会混用报告、计算设置复用。
- 弹窗验证：打开时没有自动关闭提示；Tab 到关闭按钮后可显示提示，Shift+Tab 焦点留在弹窗，Escape 正常关闭。

## 能力边界

- 浏览器数据均为隔离目录内的合成测试材料，两个标的使用相同路径用于验证流程；结果不代表真实交易收益。
- 初始 MCP 与模型集成使用协议级模拟服务测试。之后已用获准的服务端凭证验证扶摇真实日线与资讯，详见 `2026-10-21-financial-connection.md`；iFinD 与真实模型调用不在这次金融连接验收范围内。
- 执行规则目前支持趋势、均值回归以及仓位、止损止盈和持有期限约束；仅对已有兼容行情运行，不包含全市场历史数据下载。
- 比较要求明确本金；保留成本、数据覆盖和执行假设。回测可能更差，样本内或跨标的同期验证不构成未来收益保证或严格盲测。
- 不执行任何真实下单。
