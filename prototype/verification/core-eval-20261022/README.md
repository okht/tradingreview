经典案例已完成页面验收：20 笔模拟成交导入与背景确认 → 真实 AI 复盘 → 原方法与风险约束版保存 → 同条件回测 → 可编辑检查项保存 → 刷新恢复。完整 20 笔真实模型复测累计净盈亏为 **82,179.41 元**、费用 **3,115.59 元**，与独立核算一致；多周期总收益率保留未知，避免混用累计投入与账户本金。多周期汇总置空的缺陷已修复并复测。

正式交付见 [测试说明](../../../outputs/投资复盘产品-测试说明-20261022.md)，结果见 [最终运行快照](core-results.json)、[完整20笔复测截图](full20-summary-after-fix.png)。最终完整自动回归 **567/567 通过**，见 [日志](final-validation-multi-cycle.log)；本地与云端构建均通过。

自动背景准备仅完成首批 5/20 的真实验证，整组准备尚未完成；跨会话语义记忆与扩展数据接入不计入本次通过范围。下方保留原始失败、修复与阶段测试记录，阶段结论按其执行时间解读。

## 自动准备功能的验收口径

导入确认后自动生成逐笔背景候选及相关证据。背景以灰色建议显示，Tab 接受；接受前不写入已确认背景，不覆盖已有输入。接受后仍可编辑，来源按现在补充处理。证据保留来源、发布时间、与成交的关系以及原文入口。失败显示原因和重试入口，已有成交与输入保留。

此功能当前使用本组历史成交与用户已确认材料；跨会话语义记忆仍属于产品方案展望。模拟数据可用于后续方案 PPT 表征最终形态，实测报告只记当前可验证的行为。

## 5 笔分批准备与背景确认实测

同一隔离页面、相同订阅模型对 20 笔模拟成交执行分批准备。第一批 5 笔成功，页面显示 **已完成 5/20 笔**；第二批返回 **`MODEL_ERROR`**。此次错误码与上一轮整组准备的超时不同，现有证据尚不足以判定具体上游根因。

- 部分失败后保留第一批候选，页面提供「继续剩余成交」与「查看背景」，复盘输入可继续使用。没有将 5/20 显示为整组完成，也没有在失败后清空成交。
- 展开「决策背景」后，空白理由与计划中可见灰色候选。例如理由为「待确认：这笔模拟买入当时依据什么信息或判断？若记不清，可注明记不清。」候选说明明确资料包为合成测试行情，只能核对模拟行为与价格状态，无法证明主观理由或原计划。
- 在理由字段按 Tab 后，候选文字进入输入框的实际值，来源保持「现在回忆」，页面新增「AI辅助草稿，经用户确认；不等同当时记录」出处。计划字段尚未采用的内容仍以灰字显示。
- 随后人工修改理由成功；材料更新后，页面收起旧候选，保留用户新填写的背景。该操作验证了采用后可继续编辑，以及材料变化会使旧候选失效。

## 20 笔复盘失败的进一步定位

单独发出一次相同问题的 API 复现，返回 `INVALID_RESULT / CONTRACT_VALIDATION`，具体是「证据时点未知，解释必须保留不确定性」。四个必需工具均成功，65 秒左右结束。与四笔成功探测相比，这次还包含 T01 的无原始时间背景，不能只按交易数量解释差异。

随后用纯函数证明，完全归于「用户填写 / 用户自述 / 记录写到」的中性来源转述也会被拒绝。已限定修复这类误拒，仍保留未知标签；因果、当时认知和实际执行判断继续要求不确定性。校验错误增加 `text / facts[index] / interpretations[index] / learning` 路径以指导修复。原始被拒正文没有保存，因此不能断言本次真实模型原文一定正确。详见 `review20-diagnosis.md` 与 `live-probe-20.json`。

## 现在回忆背景下的页面复盘失败

随后保留 20 笔成交与 EQ01-T01 的「现在回忆」背景，在页面请求核算前四笔并生成可编辑检查项。真实模型调用执行四个工具及一次输出修复后，返回 `INVALID_RESULT`，具体提示为「interpretations[0]：基于事后回忆的解释必须明确不确定性」。截图：[recollection-validation-failure.png](recollection-validation-failure.png)。原始被拒正文未保留，不能断言该次模型原文正确。

纯函数复现发现两处校验对不确定性表述的识别不一致。「仅凭用户回忆不能证明……」「无法判断……」等四个受限表述在修复前被拒，修复后通过；两个把回忆直接当作事实的确定性解释仍被拒。对照证据：[修复前](recollection-uncertainty-baseline.json)、[修复后](recollection-uncertainty-after.json)。这些为受控契约测试，真实页面复测仍在进行，不能据此把本次失败改记为成功。
