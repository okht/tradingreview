## 实现契约

1. Design System 的 JSON 是唯一 token 来源，生成组件范围 CSS、产品全局 CSS 与 Canvas 可用的 JS 值。
2. 产品通过本地版本包依赖消费同一套值，云端构建也使用仓库内的版本包。
3. 全宽黑色顶栏与白侧栏建立导航结构。大面积灰底和米黄同步条移除。
4. 状态由图标、文字和语义色共同表达；颜色不承担唯一信息。
5. 交易、对话、决策背景、证据、方法库、设置与导入使用同一套控件状态。
6. 行情截断、交易规则、10 笔分页、工作区保存冲突处理与后端取证逻辑保持原有契约。
7. 主要执行用黑色按钮，AI 辅助操作用浅青柠色；普通取消和返回用次级样式。彩色状态均需语义图标和文字。
8. 模型连接只在实际验证成功后使用成功状态；候选规则未确认前保留待核对状态。只标记实际缺失或格式错误的字段，不把服务端连接失败归为每个字段都错。
9. 方法库顶部只保留方法名称与切换入口。来源说明、候选状态、规则描述和参数集中到「方法详情」。方法名称不自动追加版本后缀，取消版本计数与「改进版本」身份标签；底层记录与规则保持完整。
