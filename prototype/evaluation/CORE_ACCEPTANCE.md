# 核心端到端链路与异常恢复验收

优先级按用户最新要求：先证明可用主链路和失败恢复，再评价AI回答质量。此表为待执行清单，不代表已通过。使用隔离端口、隔离数据目录和构造案例；每一步记录输入、页面状态、API结果/服务版本和截图或日志证据。

推荐以一组20–40笔的fixture完成以下连续任务。模型须在隔离服务中正常授权；Windows 本地 OAuth 使用当前用户 DPAPI 加密持久化，各数据目录独立，重启后应自动恢复。仅替换页面JS不能证明服务已加载新契约。

| 编号 | 动作与输入 | 成功条件 | 必须保留的证据 |
|---|---|---|---|
| C01 导入 | 上传bundle，查看候选，确认单账户/标的范围 | 笔数、时间、价格、数量、费用逐项一致；真实标的、构造成交和合成行情标识明确；确认后才进入复盘 | fixture散列、候选笔数、确认后材料及15分钟可选周期 |
| C02 背景与证据 | 补充一笔当时记录、现在回忆、记不清；核对事前/事后/日期未知事件 | 原始陈述不被AI覆盖；来源标签和公开时点可见；用户是否看过与公开时间分开 | 每种背景状态、原文/来源/时间与对应成交 |
| C03 复盘 | 对当前决定提出具体问题，用已连接模型生成 | 实际调用模型；回答回应问题，事实/解释/未知分层；引用定位到当次快照；无自动假回复 | 模型标识、问题、工具状态、完整结果、引用定位 |
| C04 保存方法 | 从实际模式提出候选，用户选择原法或指定改进后保存 | 候选、原法、改进版本区分；只采纳指定条件；成功保存后才显示回执；不得预告收益提升 | 用户选择、结构化意图、实际方法列表、重新打开方法 |
| C05 回测 | 填入明确初始资金和范围，选择已提供兼容行情 | 资金、费用、滑点、样本关系明确；确定性结果可核算；真实行情与模拟行情分开；缺少必要项有明确阻止或降级 | 输入参数、报告口径、费用与盈亏核对、边界说明 |
| C06 学习 | 将有依据的复盘结论保存为检查项，编辑触发/动作/例外 | 经验可执行、有来源、例外可修改；材料不足时允许暂不生成；保存后进入检查项列表 | 修改前后值、来源关联、成功回执与列表 |
| C07 刷新恢复 | 刷新，再打开同一复盘、方法和检查项 | 已确认成交、背景、证据、历史回答和保存项一致；不会误把旧回答当作新模型结果；凭证生命周期说明正确 | 刷新前后数据摘要、历史引用、保存项内容 |

## 异常恢复

| 编号 | 触发 | 必须观察到的行为 | 不合格表现 |
|---|---|---|---|
| E01 非法或缺字段导入 | 重复成交、混合账户、缺成交时间、无法识别文件 | 显示具体字段问题；用户可修正/取消；原会话保持 | 静默跳过、补造价格/时间/费用、原数据被替换 |
| E02 未连接/失效模型 | 未授权、错误模型、服务断开 | 明确无法执行并给连接/重试入口；已有记录保持 | 返回预设成功回复、把失败显示成已完成 |
| E03 超时与取消 | 生成期间取消或请求超时 | 生成停止，未校验内容不成为正式回答；允许再次发送 | 无法取消、旧请求覆盖新回复、重复保存 |
| E04 行情缺失/不兼容 | 删marketData、错误标的、日期断档 | 明确缺口及影响；不从成交价生成假K线；相关比较受限 | 用正常图表或确定收益掩盖失败 |
| E05 证据查询失败 | 未配置、空结果、拒绝访问/限流 | 状态与影响明确；已有原文保留；只基于可用证据回答 | 假称检索成功、编造公告、把失败当无事件 |
| E06 材料更新 | 生成后改价格/背景/范围 | 旧答案标为材料已更新；受影响操作需重核；旧引用仍指向旧快照 | 旧解释继续冒充当前分析、无效学习被直接保存 |
| E07 保存失败/冲突 | 模拟本地存储失败、服务失败或远端版本冲突 | 无假成功回执；保留用户编辑；提供可理解恢复路径 | 丢失输入、静默覆盖、保存未完成却显示成功 |
| E08 方法与回测异常 | 无候选就保存、未知方法ID、无本金、无行情、部分改进 | 条件缺失明确，不扩大采纳范围；执行成功才写回 | 保存错方法、采用全部改进、凭空编造比较数字 |

验收记录格式：`ID / 服务版本 / fixture与场景 / 输入 / 实际输出 / 预期 / pass-fail-blocked / 证据路径 / 修复与复测`。一次成功路径与所有关键异常恢复均有实际证据后，才进入50组AI效果运行。真实模型授权缺失时C03及依赖的C04/C06须标为blocked，不能用离线规则结果代替。
