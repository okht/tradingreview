# 投资决策复盘与学习｜测试说明

测试日期：2026 年 10 月 22 日。对应题目要求：「至少覆盖主链路、数据缺失/接口失败、极端或合规边界场景」。

本说明记录已执行的测试，按输入、操作、预期、实际结果和证据说明。覆盖的经典流程为：导入成交 → 补充决策背景 → AI 复盘与引用核对 → 保存交易方法并回测 → 保存可编辑检查项 → 刷新恢复。历史失败及修复过程同时保留。

测试方式分为三种，以下逐项标注：

- **真实页面 / 真实 AI**：实际操作浏览器，调用已连接模型，保存截图与运行结果。
- **真实页面 / 确定性计算**：实际操作页面，由产品核算或回测引擎计算；没有让模型生成数值结果。
- **受控自动测试**：执行实际业务函数、API 或 Pi 运行循环，注入构造响应、接口错误或临时存储故障。使用假模型响应或回环 HTTP 服务的测试不计为真实 AI 效果。

成功条件是输入和来源保留、计算口径可核对、结论能定位证据、实际保存后才显示成功。失败条件包括补造缺失数据、用事后信息证明当时认知、输出无依据收益或直接买卖指令，以及失败后丢失用户输入。

## 6. 结论与保留事项

**题目要求的三类测试覆盖已完成。** 经典主流程已实测通过「导入 → 用户确认或手动补充背景 → 真实 AI 复盘 → 两版方法保存与回测 → 人工编辑检查项 → 刷新一致」这条路径；最终 20 笔普通问句复盘也已通过核算复测。自动批量背景准备的未完成部分单独保留如下。

本轮发现并修复一个影响主流程的缺陷：首次完整 20 笔复盘时，汇总工具只接受单个完整周期，把本组 5 个完整周期的总净盈亏返回为 `null`、`isComplete=false`，见 [修复前](../prototype/verification/core-eval-20261022/full20-summary-before-fix.png)。五个周期净盈亏分别为 13,255.30、13,984.04、14,370.21、15,671.78、24,898.08 元。修复后重新执行同一句页面请求，返回合计 82,179.41 元、费用 3,115.59 元，与独立 oracle 一致；整体收益率继续保留未知，见 [修复后](../prototype/verification/core-eval-20261022/full20-summary-after-fix.png) 与 [完整前后结果 `runs[2]` / `runs[3]`](../prototype/verification/core-eval-20261022/core-results.json)。该缺陷完成修复复测，不删除首次失败记录。

仍保留以下限制：M02 整组自动背景准备未完成，真实仅首批 5/20 成功；后续失败可保留输入与已完成候选，用户可手动补充并继续复盘。历史准备超时、`MODEL_ERROR` 和校验误拦均保留在 [过程记录](../prototype/verification/core-eval-20261022/README.md)。本次结论不泛化为全部 AI 功能、所有自然语言输入或所有金融接口均已通过。
