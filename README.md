# 投资决策复盘与学习

基于真实产品截图的交互式产品介绍。

- [连续滚动网页](https://okht.github.io/tradingreview-slidev/)
- [18 页演示版](https://okht.github.io/tradingreview-slidev/presentation.html)
- [下载高清 PowerPoint](https://okht.github.io/tradingreview-slidev/presentation.pptx)
- [下载网页 HTML](https://github.com/okht/tradingreview-slidev/raw/refs/heads/main/index.html)：下载后双击即可查看，无需安装或启动服务。

## 查看方式

网页支持章节跳转、产品流程切换、建议前后对比和截图放大。演示版可使用方向键或底部导航翻页。

网页内嵌原始 3840×2160 PNG，无外部资源依赖。PowerPoint 为 16:9 高清图像型演示稿，保留截图的尺寸比例、圆角与阴影，讲稿存放在备注中。

## 演示数据

标的身份来自真实证券；页面中的交易行为及对应测试行情为模拟数据。功能范围与测试结论以各部分注明的状态为准。50 组数据为离线校验，真实模型复盘案例单独报告。
