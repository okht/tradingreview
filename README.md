# 投资决策复盘与学习

18 页产品演示，包含真实产品页面、交互注释与测试说明。

- [直接在线打开](https://okht.github.io/tradingreview-slidev/)
- [下载高清 PowerPoint](https://okht.github.io/tradingreview-slidev/presentation.pptx)
- [下载单文件 HTML](https://github.com/okht/tradingreview-slidev/raw/refs/heads/main/index.html)：下载后双击即可在浏览器中查看，无需安装或启动服务。

## 查看方式

使用方向键或底部导航翻页；点击产品截图放大；数据源和 AI 建议页面支持切换。

网页保留可选择的文字，并内嵌原始 3840×2160 PNG。PowerPoint 为 16:9 高清图像型演示稿，保留截图的尺寸比例、圆角与阴影，讲稿存放在备注中。

## 演示数据

标的身份来自真实证券与加密资产；页面中的交易行为及对应测试行情为模拟数据。功能范围与测试结论以演示页所注明的状态为准。
